## 概要

楽譜を再現できるメトロノーム！

### 基本のメトロノーム
素早い操作を重視した設計で、テンポの調節手段を豊富に用意してある他、各種数値を縦にスワイプ(またはマウススクロール)することで連打せずに高速で微調整できます。

### 音色のカスタム
標準搭載された基本の5種類の音色に加え、自身で用意した音色を更に5パターン登録できます。
[アプリ内のリンク](https://drive.google.com/drive/folders/1uftx_yTjGCWsNSE_bHz-2QX7BZl-wYjD?usp=drive_link)(Google Drive)から様々なサンプル音色をダウンロードしてカスタム枠に登録することもできます。

### 楽曲モード　─ 合奏の味方！
メトロノームを鳴らすための楽曲データを作ることができます。
楽譜のような見た目で、でも音符を入れる必要はない…という考えから長休符で小節数を表現しています。
長休符で表された一つの区間をNamaMetoでは「小節群」と呼んでいます。
小節群には思いつく限りの柔軟な設定機能を設けました。rit.やaccel.に、裏拍を刻む機能、複合拍子、鳴らし方の個別編集、リピート記号、複数選択からのコピーや貼り付けや削除、などなど。

### 再生モード
楽曲データ作成と対になる「再生モード」も快適さを追求しています。
演奏開始前の予備拍(カウントイン)。繰り返しの2回目でも、練習記号から4小節目でも、好きな場所から開始できる機能。再生速度を変えて練習する「倍率」機能(縦スワイプで秒速調整可能！)。迷子にならないための読み上げ機能(拍のカウントや練習記号名など)。

### 万全のバックアップ
全ての設定はファイルとして出力できます。
まとめて出力するフルエクスポートの他に、音色や楽曲を1つずつ出力する機能もあり、演奏メンバーとのデータ共有ができます。

### アプリ化に対応
ブラウザ上で動作するアプリですが、各種OSにインストールする機能があります。(詳細はアプリ内「設定」タブの下部に記載)
インストール後はホーム画面やデスクトップに置くことができ、オフラインでの動作が可能で、通信できる時にリロードすると最新の安定版に自動更新されます。

### 画面説明（スクリーンショットの見方）
1) メトロノーム画面: テンポは数字の縦スワイプやスクロール、±ボタン、タップテンポで調整。ビートパターンで拍ごとの強・中・弱・無を切り替え、プリセットは10枠まで保存できます。
2) 設定画面: 音色の登録（基本5種＋自作5枠）、テーマカラー、フラッシュ／バイブ、音声・外部機器での操作、データの入出力はここに集約されています。
3) 楽曲モード（作成編集）: 小節群を並べて一曲分を作成。小節数・テンポ・拍子を小節群ごとに設定でき、rit.／accel.やリピート記号にも対応します。
4) 楽曲モード（再生）: 開始位置を小節群・小節単位で指定でき、予備拍（カウントイン）つき。倍率で速度を変えた練習や、音声読み上げで現在位置を見失いません。

### その他の機能
フラッシュやバイブレーションでも拍を確認でき、音声認識や外部機器で再生／停止の操作もできます。スリープ防止、テーマカラーの変更、楽曲データのMP3保存など、練習の現場で効く小ワザも揃っています。
